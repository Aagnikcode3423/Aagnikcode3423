## 🟠 03 / FEATURED ENGINEERING PROJECT

### MACHGUARD — Machine Health & Multi-Hazard Detection

<p align="center">
  <img src="https://img.shields.io/badge/PROJECT-MACHGUARD-F59E0B?style=for-the-badge" alt="MACHGUARD"/>
  <img src="https://img.shields.io/badge/FOCUS-MACHINE%20HEALTH-06B6D4?style=for-the-badge" alt="Machine health"/>
  <img src="https://img.shields.io/badge/NEXT-DIGITAL%20TWIN-8B5CF6?style=for-the-badge" alt="Digital twin"/>
</p>

An engineering project focused on machine-health monitoring and multi-hazard detection using sensors and embedded systems.

### Project roadmap

| Module | Objective |
| :--- | :--- |
| Sensor monitoring | Collect machine and environmental measurements |
| Hazard detection | Identify configured hazardous conditions |
| Machine dashboard | Visualize operating conditions and status |
| Digital twin | Represent a machine through interactive parameters |
| Fault detection | Investigate abnormal machine behaviour |
| Predictive maintenance | Explore ML-based fault prediction and maintenance planning |

**Technology direction:** ESP32, sensor systems, HTML, CSS, JavaScript, Three.js, Python and machine learning.

The digital-twin and predictive-maintenance capabilities are part of my development roadmap. I aim to implement and validate them incrementally.
